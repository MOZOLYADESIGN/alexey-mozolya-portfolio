# Content layer

Редактируемые тексты, SEO-данные и контактные ссылки находятся только в `site.json`.

`schema.ts` задаёт разрешённую структуру, запрещает неизвестные поля и HTML в текстах, а также проверяет HTTPS, Telegram URL, email и состав проектов. `render.ts` экранирует все значения и подставляет их в статический HTML во время Vite build. Проекты рендерятся из массива, но могут использовать только один из заранее разрешённых наборов локальных изображений.

Telegram CMS из `cms-worker/` изменяет только `site.json` в отдельной `bot/update-*` ветке и обязана проходить `npm run check`. Доступ к произвольным HTML, CSS и JavaScript ей не требуется.
