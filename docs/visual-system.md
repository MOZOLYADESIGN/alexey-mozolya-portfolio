# Визуальная система

## Характер

Светлая авторская редакционная среда. Типографика задаёт структуру, а насыщенный визуал живёт внутри проектов, продуктов и hero-объекта. Интерфейс не должен выглядеть корпоративным SaaS-шаблоном.

## Цвет

```css
--color-bg: #f8f8f7;
--color-surface: #ffffff;
--color-text: #0b0b0b;
--color-muted: #666663;
--color-border: #deded9;
--color-focus: #1d5cff;
```

UI остаётся монохромным. Цветовые пары задаются в данных проектов/продуктов и не становятся общими UI-токенами.

Placeholder palettes:

- ultramarine / cyan;
- magenta / coral;
- lime / yellow;
- violet / ice blue;
- orange / peach;
- teal / electric blue;
- red / pink;
- acid green / sky.

## Типографика

- Grotesk: Onest Variable.
- Serif: Lora Variable Italic.
- Кириллица обязательна.
- Шрифты поставляются локально через npm-пакеты Fontsource.
- Антиква используется только как акцент, не для длинного основного текста.

Ориентировочная шкала:

```css
--font-hero: clamp(3rem, 8vw, 9rem);
--font-h2: clamp(2.25rem, 5vw, 5.5rem);
--font-h3: clamp(1.5rem, 2.4vw, 2.75rem);
--font-body-lg: clamp(1.125rem, 1.5vw, 1.5rem);
--font-body: 1rem;
--font-meta: 0.875rem;
```

## Пространство

Базовая шкала: 4, 8, 12, 16, 24, 32, 48, 72, 96, 144.

```css
--container: 1480px;
--page-gutter: clamp(1rem, 4vw, 4rem);
--section-space: clamp(5rem, 10vw, 10rem);
```

## Радиусы и тени

```css
--radius-sm: 16px;
--radius-md: 24px;
--radius-lg: 36px;
--radius-xl: 52px;
--radius-pill: 999px;
--shadow-soft: 0 18px 55px rgb(0 0 0 / 0.055);
```

На мобильном радиусы обычно уменьшаются на один шаг.

## Коллаж

- Overlap используется только на `min-width: 1024px`.
- Каждый overlap задаётся явно, без случайных transforms.
- Интерактивные области не должны перекрывать друг друга.
- Z-index описывается токенами: base, raised, nav, overlay.
- На мобильном все элементы возвращаются в normal flow.

## Изображения

- Обложки проектов: предпочтительно AVIF/WebP, фиксированное соотношение сторон.
- Постеры: AVIF/WebP.
- Прозрачная анимация: WebM; предусмотреть poster.
- Нельзя использовать тяжёлые PNG, если прозрачность не нужна.
- Медиа не должно вызывать layout shift.

## Запрещённые визуальные решения

- стеклянные панели повсюду;
- насыщенный градиент как фон всей страницы;
- одинаковые bento-карточки во всех разделах;
- декоративный blur на мобильном;
- кастомный курсор;
- постоянный параллакс;
- мелкий серый текст с низким контрастом;
- анимация, меняющая доступную область текста во время чтения.
