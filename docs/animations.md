# Анимационная система

## Общий принцип

Движение создаёт характер в двух точках: hero и портфолио. Остальные секции используют только короткие, функциональные transitions.

## Hero

- Центральная выключка; позади — 5 концентрических кругов.
- Пульс `ripple` бежит от внешнего кольца к центру (задержки по кольцам), фокусируя внимание в центре.
- Анимируются только opacity и transform (scale).
- Радиальная заливка в цвет фона поверх кругов и под текстом — круги растворяются в центре.
- При reduced motion круги статичны.

## Карточка проекта

Блок — галерея, а не карточки: изображение без подложки.

С брейкпоинта 768 px (по Figma):

- идея и результат — обычный текст под изображением;
- текст виден всегда, наведение ничего не перекрывает и не двигает;
- изображение остаётся полностью видимым.

Ниже 768 px:

- текст виден сразу поверх нижней части изображения;
- нижняя часть картинки уходит градиентом в цвет фона, текст лежит на переходе;
- без blur и без backdrop.

## Навигация

- `isCompact = scrollY > threshold`;
- возврат полной высоты только при `scrollY` около 0;
- hover/focus не разворачивает капсулу;
- transition только по внутренним padding, background, border, color;
- hit area сохраняет минимум 44 px даже в компактном виде через внешний интерактивный контейнер.

## Услуги (аккордеон)

- раскрытие ~420 ms с выразительным ease-out, сворачивание ~260 ms; высота анимируется на обёртке, а контент подъезжает снизу (translateY + opacity) с небольшой задержкой — живее;
- анимация на Web Animations API из client-компонента; padding вынесен на внутренний элемент, чтобы при height 0 не оставалось зазора;
- desktop — несколько карточек открыто одновременно; смартфон — аккордеон, открытие одной закрывает остальные;
- при reduced motion анимации нет, карточка открывается/закрывается мгновенно.

## Появление секций

- opacity + translateY 12–24 px;
- один запуск;
- без stagger длиннее 500 ms;
- не скрывать основной текст до выполнения JavaScript;
- при reduced motion сразу показывать финальное состояние.

## Продуктовая врезка (инверсия темы)

- IntersectionObserver с `rootMargin: -32%` включает `data-active`, когда врезка в средней части экрана.
- Тема выражена через `--co-*` переменные; при активации фон/текст/границы/кнопка инверсируются с переходом ~600 ms.
- Сходящиеся вверх стрелки пульсируют волной снизу вверх (`arrowRise`), при reduced motion статичны.

## GSAP

Подключать GSAP только в client-компоненте и только после подтверждения сцены. Использовать `gsap.context()` и корректный cleanup. Не pin-ить длинные разделы и не перехватывать нативный scroll.

## Производительность

- На смартфоне отключить WebM, blur, parallax и сложные ScrollTrigger-сцены.
- Не анимировать большие blur-radius и box-shadow.
- Предпочитать transform и opacity.
- Проверять memory и main-thread time.
