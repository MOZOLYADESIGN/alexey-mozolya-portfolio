# Доступность и контроль качества

Целевой уровень: WCAG 2.2 AA.

## Обязательная доступность

- Skip link.
- Семантические `header`, `nav`, `main`, `section`, `footer`.
- Видимый `:focus-visible`.
- Полная клавиатурная навигация.
- Hover-состояния доступны по focus.
- Минимальная интерактивная зона 44×44 CSS px, где возможно.
- Контраст обычного текста минимум 4.5:1.
- Контраст крупного текста минимум 3:1.
- Никакой информации только через цвет.
- Alt-тексты для смысловых изображений; пустой alt для декора.
- Состояние раскрытых услуг передаётся через `aria-expanded`.
- Мобильное меню управляет фокусом и закрывается Escape.
- `prefers-reduced-motion` отключает необязательное движение.
- Контент остаётся доступным без выполненных анимаций.

## Viewports

Минимальный набор:

- 360×800;
- 390×844;
- 768×1024;
- 1024×768;
- 1440×900;
- 1920×1080.

## Проверки каждого блока

1. `npm run typecheck`
2. `npm run lint`
3. `npm run build`
4. `npm run test:a11y`
5. ручная проверка клавиатурой
6. проверка reduced motion
7. проверка переполнения на 320–360 px

## Lighthouse

Цели для production-like build:

- Accessibility ≥ 95;
- Best Practices ≥ 95;
- SEO ≥ 95;
- Performance ≥ 85 на mobile и ≥ 95 на desktop после появления реальных медиа.

Показатель не принимается ценой удаления ключевой идеи. Сначала находить тяжёлые ассеты, лишний JS и дорогие эффекты.

## Критерии готовности блока

- соответствует утверждённой композиции;
- не ломает предыдущие блоки;
- работает мышью, клавиатурой и touch;
- не создаёт горизонтальный scroll;
- не содержит фальшивого контента;
- проходят автоматические проверки;
- доступен локальный preview.
