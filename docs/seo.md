# SEO-спецификация

## Цель

Основной кластер: дизайн сайтов и цифровых продуктов. Вторичные: дизайнер интерфейсов, бренд-стратег, арт-дирекшн, дизайн образовательных и B2C-продуктов.

География: вся Россия, удалённая работа.

## Metadata

Title:

> Дизайн сайтов и цифровых продуктов — Алексей Мозоля

Description:

> Алексей Мозоля — дизайнер интерфейсов и бренд-стратег. Проектирую сайты и цифровые продукты, развиваю визуальные системы и коммуникацию брендов.

Description перед публикацией проверяется автором и ограничивается примерно 150–165 знаками.

## Иерархия

- Один H1.
- Основные секции — H2.
- Карточки услуг и продуктов — H3.
- Не использовать заголовки ради визуального размера.
- Авторская фраза может быть H1, если рядом до первого экрана присутствует ясное описание услуги.

## Техническое SEO

- статический HTML;
- canonical после появления реального домена;
- `robots.ts` и `sitemap.ts` после появления домена;
- Open Graph image 1200×630;
- favicon и web manifest — позже, без PWA;
- семантические landmarks;
- alt-тексты описывают содержимое, не повторяют подпись;
- внутренние якоря имеют устойчивые id.

## Будущее расширение

- `/notes` и `/notes/[slug]` генерируются статически из файлов;
- `/en` получает собственные metadata и `hreflang`;
- не создавать пустые маршруты заранее;
- страницы кейсов не создаются, пока пользователь явно не изменит решение.

## Тексты без SEO-спама

Ключевые слова используются в ясных описаниях услуг и metadata. Не повторять «дизайн сайтов» в каждом блоке. Авторский голос важнее механического насыщения.
