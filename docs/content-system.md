# Контентная система

## Принципы

- Контент отделён от компонентов.
- Все структуры типизированы.
- Пустой или выключенный элемент не отображается.
- Нельзя заполнять обязательные поля выдуманным текстом ради красивого preview.
- Placeholder-данные явно маркируются `isPlaceholder: true`.

## Главная фраза и описание

Сохраняется фраза:

> Прокачиваю смыслы, визуал, стратегию и коммуникацию цифровых продуктов.

Рабочая поясняющая формулировка:

> Помогаю цифровым продуктам становиться сильнее по смыслу и визуально: анализирую продукт, нахожу точки роста и собираю стратегию развития.

Перед публикацией текст редактируется автором. Не добавлять недоказанные формулировки про «сотни тысяч рублей» без конкретных данных.

## Ограничения по объёму

| Элемент | Ограничение |
| --- | --- |
| Hero H1 | 90–130 знаков |
| Hero subtitle | до 180 знаков |
| About | 350–650 знаков |
| Принцип | заголовок до 40, текст до 160 знаков |
| Пояснение к проекту | до 200 знаков |
| Услуга summary | до 220 знаков (текст раскрытой панели, не свёрнутый ярлык) |
| Мысль preview | 250–500 знаков |
| CTA продукта | до 500 знаков без списка |
| FAQ answer | 250–600 знаков |

## Проект

Обязательные поля:

- `id`;
- `title`;
- `category`;
- `summary`;
- `cover` или placeholder gradient;
- `alt`;
- `isPublished`;
- `isPlaceholder`.

Никакого `href` на страницу кейса. CTA карточки вычисляется как Telegram-ссылка.

## Услуга

- название;
- короткий результат;
- цена;
- подробности для inline-раскрытия;
- этапы или состав;
- CTA в Telegram.

Не публиковать сроки, число правок и универсальную схему оплаты.

## Продукт

Структура:

1. контекстная строка, связывающая продукт с предыдущим блоком;
2. название;
3. кому подходит;
4. какой результат;
5. формат;
6. что входит;
7. цена;
8. Telegram CTA.

## Доказательства

Допускаются только реальные:

- измеримый результат;
- название клиента;
- логотип с разрешением на публикацию;
- число студентов или программ;
- отзыв с именем и ролью.

Если данных нет, секция не рендерится.

## Мысли

В MVP мысли работают в двух режимах:

- короткие редакционные вставки между секциями;
- компактный preview будущего `/notes`.

Ссылки на несуществующие страницы запрещены. Поле `futureSlug` можно хранить, но `linkEnabled` остаётся `false`.

## Контактные данные

Все адреса находятся в одном объекте `siteConfig.contacts`. Не дублировать URL строками внутри компонентов.
