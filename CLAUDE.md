# Инструкции для Claude Code

Перед любым изменением прочитай `MASTER_PROMPT.md`, затем документы из `/docs` в указанном там порядке.

Ключевое правило: работа ведётся по одному блоку. После каждого блока запусти локальный preview и остановись до подтверждения пользователя. Утверждённый блок фиксируется отдельным Git-коммитом.

Нельзя придумывать контент, клиентов, результаты и отзывы. Нельзя добавлять бэкенд, формы, попапы, CMS, аналитику, оплату или отдельные страницы кейсов без новой прямой задачи.
